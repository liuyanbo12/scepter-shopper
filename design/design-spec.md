# 京东购物 Agent 设计说明

主屏参考：`primary-screen-concept.png`，由内置 Image Gen 生成的完整空状态，已读取检查。界面采用真实白底，京东红强调，克制双栏工具布局。无商品样例、无模拟进度。

## 设计系统

- 颜色：背景 #ffffff；左侧浅灰 #f6f7f9；主文字 #20222b；次文字 #697180；边框 #e7e8ed；强调 #e33232；错误 #b42318；成功 #25805e。
- 字体：优先 Microsoft YaHei / PingFang SC，Latin 使用系统 sans-serif。标题 36/46，区域标题 17/26，正文 14/23，小字 12/20，按钮 14/22。
- 间距：4、8、12、16、20、24、32、48。主内容边距 32；两栏间距 20。
- 容器：顶部 80px 导航，主标题说明，左栏 340px，右栏自适应；面板边框 1px，圆角 8px，按钮 8px。无重阴影。
- 图标：代码原生 SVG，线性 1.6px 描边，指针品牌图形实心白色。仅使用鼠标指针、外链、箭头、清单、暂停、停止、播放、勾选、刷新等明确图义。
- 状态：初始空白 → 规划 → 搜索 → 等待确认 → 加购 → 核验；暂停/用户接管/失败提供就地说明与控制。
- 核心组件：Header、TaskComposer、ProgressRail、ResultWorkspace（需求/候选/日志/购物车）、History；所有内容由后端实际数据驱动。
- 移动布局：900px 以下上下排列，保留完整控件；候选信息改成纵向条目，没有横向溢出。

## 与概念有意的差异

为必需功能补充 API Key 缺失提示、当前任务控制、历史记录及购物车结果标签；这些状态未在空状态概念里显示，沿用同样的平面列表和文字层级。不把密钥放进前端、不把自定义模型名硬编码成已连接。

## 概念提示词摘要

完整中文桌面工具主屏；白底、京东红、双栏；左侧购物需求输入和五阶段轨迹，右侧需求清单/商品候选/执行日志与空状态；真实浏览京东、页面文字优先、加购前确认；不造商品和进度。内置 image_gen 生成。
