# 前端实现与验收记录

本文件记录早期界面验证。2026-10-21 整理目录后，旧截图和 JSON 结果已移至 `../.cleanup-archive/20261021/qa/`；下文原路径仅用于说明当时的产物，不代表当前版本已经通过相同验证。

## 范围

已实现独立本地应用的 React/Vite 界面：自然语言输入、需求清单、真实候选展示、分类互斥选择、后端预算/兼容性检查、确认加购、任务控制、日志、购物车结果、历史只读与网络错误处理。产品没有内置商品样例、假进度或模拟成功。

API Key 保留在后端 `.env`。前端只读取 `key_configured`，不接触密钥；保存配置后自动刷新连接状态，无需重启。打开浏览器请求单独允许 60 秒，遇到 `needs_user` 显示后端实际提示。

## 设计对照

内置 Image Gen 概念：`design/primary-screen-concept.png`（1536×1024）。已使用 `view_image` 直接检查概念和最新桌面、移动截图。

对照项目：

1. 真白背景、浅灰左栏与细灰边框保留，未添加渐变或重阴影。
2. 两栏比例、顶部品牌/打开京东按钮、标题层级与左右面板位置对应概念。
3. 红色主动作与当前标签下划线一致；缺少 Key 时主动作变为真实禁用状态。
4. 输入区、五阶段进度、状态行与右侧清单/候选/日志组织一致。
5. 空状态清单图标、居中标题与说明、底部依据说明保留。
6. 桌面和移动截图均无水平溢出、控件裁切或遮挡；移动端以纵向布局保留功能。

已修正的主要偏差：大屏左栏原先偏窄，调整到约 31%；中文字体优先 Microsoft YaHei UI / Microsoft YaHei；正文和配置提示提升为 14px，候选标题 15px，元信息至少 12px。

有意差异：真实缺 Key 提示增加一行配置区域；禁用按钮使用浅红；底部展示后端实时观察方式；历史、控制、验证、购物车等运行态沿用同一设计系统。首屏原有文案没有意外新增营销词或删除核心内容。字体使用本机可用中文字体，其字形不会与生成图片逐像素相同。

## 验证结果

- `npm run build`：TypeScript 检查与 Vite 生产构建通过，包含 `package-lock.json`。
- 真实本地服务：`http://127.0.0.1:8766/`；桌面与移动截图通过项目内 Playwright + headless Edge 获得。Browser 插件未列入可用技能，因此采用 Playwright 路径。
- `qa/frontend-smoke.json`：页面身份、非空、无框架错误、控制台无相关错误、缺 Key 阻止启动、输入及标签切换、双尺寸无溢出均通过。
- `qa/frontend-state-smoke.json`：使用隔离的 API fixtures，验证分类互斥选择、超预算禁用加购、正确选品 ID 提交与 adding 状态，均通过且无运行时错误。该测试没有调用模型、操作京东或写真实购物车。

截图：`qa/frontend-desktop.png`、`qa/frontend-mobile.png`。根代理重新运行两份前端烟测后，已再次直接读图检查。

尚未验证：用户真实 DeepSeek API Key 的调用、京东真实搜索/加购端到端成功率。它们依赖后端执行器和用户登录态，前端 smoke 不代表已完成真实购买链路。
